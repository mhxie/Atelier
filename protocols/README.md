# Protocols — Quick Reference

Load-when-needed index. Route through `AGENTS.md` and the selected procedure
first. Consult this index only to locate an additional contract; its entries
are not a startup checklist or a chain of required reads.

## By Agent

Use the selected agent brief and its active handoff contract. Other agents'
contracts are needed only when sending or receiving their outputs. Scoring,
coaching, note operations, and maintenance protocols apply when that task is
in scope. Meeting and Librarian remain intent-specific dispatches.
